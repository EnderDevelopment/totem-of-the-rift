# Totem of the Rift Minecraft Plugin

Totem of the Rift is a Minecraft plugin that adds a custom Totem of Undying with persistent item identification, potion effects when selected in the hotbar, and combat effects when used to attack another player.

## Install

1. Build the plugin from its source code to produce a plugin JAR.
2. Copy the JAR into the `plugins` folder of a Minecraft server that supports the plugin's declared API version, 1.21.
3. Start or restart the server.

## Use

1. Run `/give_totem` as a player to receive the custom totem.
2. Select the totem in your hotbar. The plugin applies Strength I, Speed I, Fire Resistance, and Resistance for 60 seconds.
3. Attack another player while holding the totem in your main hand to apply Slowness, Blindness, and Poison to that player.
4. Hold the totem in your offhand to prevent fall and explosion damage.
